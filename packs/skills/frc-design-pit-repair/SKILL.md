## When to use
Before and during events, after every match, and when planning spares during build season.

## Between every match (5-10 minutes)
1. Battery: swap to a fully charged one (check voltage and internal resistance with a battery analyzer if you have one); secure the Anderson connector.
2. Walk-around: loose or missing bolts (witness marks), cracked polycarbonate, bent tubes, rubbing wires, frayed rope, loose chain/belts.
3. Drivetrain: wheels/tread wear, module steering free, no new noises; spin each wheel.
4. Mechanisms: run each through its full range (on a cart), check hard stops, encoders zeroed, game-piece sensors working.
5. Pneumatics: leaks, pressure gauges, fittings.
6. Electrical: CAN lights, radio power, breaker seated, no metal chips near electronics.
7. Bumpers: correct color, secure, numbers visible.
8. Log anything found (what, which match, fix) so trends show up.

## Spares and tools
- Spares: swerve module (assembled), motors and controllers, intake rollers and wheels, belts/chain and master links, polycarbonate plates, shafts, bearings, fasteners, rivets, zip ties, tread, battery leads.
- Tools: hex keys/drivers for every fastener size used, rivet gun, drill, Loctite, wire tools, multimeter, zip ties, spare radio and roboRIO if possible.
- Pre-made repair kits per subsystem with the exact parts and a laminated procedure.

## Rules of thumb
- Fix the cause, not just the symptom (a part that broke once will break again).
- Changes at an event: small, tested on the cart, and reweighed if they add material.
- Assign roles: pit lead, mechanical, electrical, battery, scouting liaison.

## Common mistakes
- No checklist; things missed under time pressure.
- Spares that don't match the robot's current version.
- Untracked weight added during repairs.
