## Shape the question
Rewrite as "How might we ... for ... so that ...?" Note the goal, audience, constraints (budget, time, rules) and what "good" means. If memory has the user's preferences, use them.

## Diverge (quantity first, no judging; aim for 30+)
Use 3-4 of these, labeled, so the user sees range:
- SCAMPER on an existing thing: Substitute, Combine, Adapt, Modify (magnify/minify), Put to another use, Eliminate, Reverse/Rearrange.
- First principles: list the fundamental truths and costs; rebuild the solution from them, ignoring how it's done today. ("A battery pack costs X because of materials Y; what if we buy cells directly?")
- Analogies: how does another field solve the same structure? (Hospital triage for a support queue; airline yield pricing for a salon.)
- Constraints: force variety. "With $0", "in 24 hours", "for a 7-year-old", "if it must be 10x cheaper", "if we couldn't use software".
- Inversion: how would we guarantee failure? Then flip each.
- Random stimulus: pick an unrelated word or object and force a connection.
- Worst idea first: deliberately bad ideas often contain a good kernel.
- Extremes and personas: the power user, the skeptic, the beginner, a competitor.
For research-backed domains, quickly web_search what already exists so ideas are novel, and say which are known.

## Converge
1. Cluster similar ideas; name each cluster.
2. Score the top 8-10 on impact, feasibility, cost, novelty, fit (simple 1-5 matrix, or impact vs effort 2x2).
3. Pick 1-3 and strengthen each: what would make it 2x better, what's the cheapest test, what's the main risk.

## Output format
Short framing line, ideas grouped by method (one line each), the scoring table, top picks with next steps. Offer more rounds in a direction the user likes. For business ideas, hand off to ideas-new-business or ideas-validate-business.

## Pitfalls
Stopping at the first 5 obvious ideas; judging during divergence; ideas that ignore stated constraints; generic lists without specifics (names, numbers, examples).

## Verify
Re-read the constraints and drop violators; check novelty claims with a quick search; make sure each top pick has a concrete first step.
Ideas that touch law, money, health or safety are starting points: before acting, consult a professional in that field (a lawyer, accountant, clinician or engineer).
