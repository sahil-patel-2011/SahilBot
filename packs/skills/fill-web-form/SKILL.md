name: fill-web-form
description: Fill in an online form accurately and safely.
source: you
uses: 0
category: Research
---

1. Open the form and snapshot it. List every required field.
2. Use only information the user gave or that's saved in memory; ask for anything missing instead of inventing it.
3. Passwords only via fill_secret. Never type card numbers, government IDs or passwords yourself.
4. Fill all fields in one batch, then snapshot to verify each value before submitting.
5. Submitting needs the user's OK; afterwards confirm what the page says (confirmation number, email).
