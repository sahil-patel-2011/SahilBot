1. Structure: summary (decision and key numbers), requirements, design/approach, analysis with calculations, verification/tests, risks and open issues, references.
2. Every number has units and a source or calculation; long calculations go in an appendix table.
3. Include figures (plots, diagrams) as images and reference them.
4. Create it with create_document (docx or pdf) and re-open it to check.
