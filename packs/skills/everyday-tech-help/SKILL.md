## Approach
Ask device, model, OS version and exactly what happens (error text, when it started, what changed). Give one step at a time for less technical people, with what they should see after each step. Settings paths change between versions: look up the current official support page (support.apple.com, support.google.com, Microsoft, the router or printer maker) and cite it.

## Wi-Fi and internet
1. Is it one device or all? One device: forget network and rejoin, restart device, update. All devices: restart modem first, wait ~1-2 minutes, then router.
2. Speed test near the router vs far away: weak far away means coverage (move router central and high, away from microwaves and thick walls; consider mesh Wi-Fi). Slow everywhere: check the plan's speed, then call the ISP.
3. 2.4 GHz reaches farther, 5/6 GHz is faster but shorter range; smart-home gadgets often need 2.4 GHz.
4. Security: change the router's default admin password, WPA2/WPA3, firmware updates, guest network for visitors and smart devices.

## Printers
Check power, paper, ink and error lights; same Wi-Fi network as the computer; clear the print queue; remove and re-add the printer (AirPrint on Apple devices needs no driver); download drivers only from the manufacturer's site.

## Phones and computers
Storage full: largest apps, photos to cloud or computer, offload unused apps, clear message attachments. Backups: iCloud/Google backup and a computer or external drive copy (3-2-1 rule: 3 copies, 2 media, 1 off-site). Slow computer: restart, updates, close startup apps, free disk space (10-15% free is a common guide).

## Accounts and security
Password manager, unique passwords, two-factor authentication (authenticator app or passkeys preferred over SMS), recovery contacts and codes written down and stored safely. Enabling or changing security settings is the user's job: guide them through it rather than doing it.

## Scams (teach this)
Real companies don't cold-call about viruses, don't ask for gift cards or remote access, and don't send urgent "your account is locked" links. Hang up, call the official number. If remote access was granted: disconnect from internet, run security scans, change passwords from another device, call the bank if financial info was shared. Report at reportfraud.ftc.gov.

## Tools
Can walk through steps on this Mac with the app tool or computer use when the user asks; never type passwords or approve 2FA prompts for them. Write a simple printed guide (create_document .pdf, big font) for a family member if useful.
