## When to use
Any design decision that touches size, reach, weight, motors, parts cost or inspection. Rules change every season: treat the numbers below as the 2026 example and confirm in the current manual and Team Updates.

## Steps
1. Find the current Game Manual (FIRST site) and the robot construction rules section (2026: section 8, "R" rules). Read the Team Updates; they amend the manual through the season. Use the official Q&A for unclear rules.
2. Put the numeric limits into the layout sketch as constraints: robot perimeter outline, extension zones, max height, bumper zone.
3. Track weight from day one (frc_mech weight_budget) with a margin.
4. Check every COTS item against cost and legality rules; keep receipts and a cost list if required.
5. Before bag-and-tag-style deadlines or events, run a self-inspection with the official checklist.

## 2026 example numbers (verify)
- R101/R104: robot perimeter is fixed structure; starting configuration ≤ 110 in perimeter and ≤ 30 in tall.
- R105/R106: extension ≤ 12 in beyond the robot perimeter, over one side at a time. R107: height ≤ 30 in.
- R103: weight ≤ 115 lb without bumpers, battery and tags. R408: ≤ 135 lb with bumpers.
- R301: no single non-KOP item worth more than $600.
- R501/R502: only listed motors; a cap on propulsion (drive) motors.
- 2026 renamed "frame perimeter" to "robot perimeter" in Team Updates: older guides use the old term.

## Checks
- Layout sketch shows the perimeter, every extension and the height limit in every robot state.
- Weight margin ≥ ~5 lb entering competition.
- Nothing extends over two sides at once (if that rule applies this year).

## Common mistakes
- Using last year's numbers.
- Measuring extension from the bumper instead of the defined perimeter.
- Forgetting the battery and bumpers in total-weight checks where the rule includes them.
