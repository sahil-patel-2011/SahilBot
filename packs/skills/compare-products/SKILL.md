1. Pin down the criteria that matter to the user (budget, must-haves, deal-breakers). Ask once if they're unknown and it matters.
2. Find current info from official pages (pricing pages, spec sheets) with dates; use helpers in parallel for many options.
3. Build a comparison table: same columns for every option, real prices with currency and billing period, sources.
4. Recommend one with the reason in a sentence, and say when another option would be better.
