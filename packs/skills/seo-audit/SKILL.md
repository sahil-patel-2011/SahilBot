1. Crawl key pages with the browser or fetch_page: titles, meta descriptions, headings, internal links, schema, speed signals, mobile.
2. Indexing basics: robots.txt, sitemap.xml, canonical tags, HTTPS, broken links.
3. Content: does each important page answer a clear search intent with helpful, original content? Local businesses: Google Business Profile, consistent name/address/phone, reviews.
4. Use connected SEO tools (for example Semrush via find_tools) for keywords and backlinks when available.
5. Deliver a prioritized list: issue, page, impact, fix.
