source: you

1. Write the knowns with units and the unknown. State assumptions.
2. Find the right formula from a reliable reference and cite it if it isn't common knowledge.
3. Compute in Python (the pint package handles units if installed); never do multi-step arithmetic in your head.
4. Sanity-check: order of magnitude, units of the result, limiting cases, a second method when possible.
5. Present the formula, inputs, result with units and sensible precision, and what it means.
